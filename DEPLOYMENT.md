# Deployment

## GitHub Pages

1. Upload all files in this folder to the GitHub repository.
2. Commit the changes.
3. GitHub Pages will rebuild automatically.

Live URL:

```text
https://malihazohebuk-neeyat.github.io/neeyat-web-app/
```

## Vercel Future Version

For the future full-stack version:

1. Convert the app to Next.js.
2. Add environment variables.
3. Add database migrations.
4. Seed the database.
5. Deploy through Vercel.
